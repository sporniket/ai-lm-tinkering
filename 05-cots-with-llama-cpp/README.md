# «Components On The Shelf» experimentation with llama.cpp

The goal is to use existing engines and coding assistants to tests compact inference models using CPU only.

More specifically, use bit/ternary models, like Bonsai. Other models can be assessed too.

Depending on the results, I **MAY** experiment with tighter profiles.
